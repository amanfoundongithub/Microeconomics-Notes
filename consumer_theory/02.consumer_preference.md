# Consumer Preference

The first topic we want to understand in this section will be to model the consumers' preferences and understand how they make decisions when faced with a set of choices.

After reading this section, you will be able to understand how to model the consumer preferences mathematically.

## Consumption Bundle

The first step in modelling the consumer preference is to first understand the way in which we can represent the consumption.

More specifically, suppose there are $n$ goods available to a user for consumption. Suppose a consumer has a consumption of $x_i$ of the $i^{th}$ good. How do we represent the overall consumption of the consumer?

This question is important, because we will use the notation discussed here in the rest of the discussion. For now, how will we answer this question?

In economics, we typically call this overall consumption by the consumer as their `consumption bundle`.

To ensure that there is no mathemtical way of comparing the bundles, we can write the consumption bundle as a tuple of $x_i$ as follows:

**Consumption Bundle of Consumer = $(x_1, x_2, ..., x_n)$**

Usually, economists prefer to denote this by capital letter $X$. Thus, we will denote the consumption bundle in the description as either $X$ or $(x_1, x_2, ..., x_n)$, whichever suits the context.

## Consumer Preference - Definition

Now that we know how to represent the consumer's consumption bundle, we can now easily understand and model a consumer's behavior.

For this, we will define a notion of preference for a consumer. This notion will be extremely useful for understanding a consumer's behavior. For now, we define the preference as follows:

Consider two bundles $X$ and $Y$ from the same market. For a consumer, we can say that:

- If the consumer wants to have bundle $X$ over $Y$, we say the consumer **_prefers_** $X$ over $Y$. This is written mathematically as:

<p align = 'center'>
    $X \succ Y$
</p>

- If the consumer is equally wanting to have bundle $X$ over $Y$, we say the consumer is **_indifferent_** between $X$ and $Y$. This is written mathematically as:

<p align = 'center'>
    $X \sim Y$
</p>

- If both the previous conditions hold, meaning that the consumer can will not prefer $Y$ over $X$, we can say that the consumer **_weakly_** prefers $X$ over $Y$. This is written mathematically as:

<p align = 'center'>
    $X \succeq Y$
</p>

These notations are very important because we will be using them to derive some interesting properties.

But before we can delve more into how these works, we need to make some consistency assumptions regarding the preferences, which are explained below.

## Axioms of Consumer Preference

To simplify the notion and be able to make some definitive predictions, we need to make some assumptions about the consumer preference. These assumptions are as follows:

1. **Completeness**: Given any two bundles $X$ and $Y$, they can always be compared i.e. the consumer would always have either $X \succ Y$, $X \sim Y$ or $Y \succ X$. This could be condensed to: either $X \succeq Y$ or $X \succeq Y$ or both.

    - While this looks pretty obvious, it does not take into account the fact that a consumer's taste may change over the time. Nonetheless, for a short period of assumption, the consumer's taste can be assumed to be constant.

2. **Reflexivity**: For a given bundle $X$, it is always as good as itself i.e. we have $X \succeq X$.

    - This is essentially true for almost all adult consumers. They will view the same item with same preference every time they are provided with the choice.

    - However, if we consider toddlers, their preference will change every time we face them with the same bundle, which will be a contradiction to this.

    - Nonetheless, we can assume that the reflexivity holds well.

3. **Transitivity**: For three bundles $X$, $Y$ and $Z$, if we have $X \succeq Y$ and $Y \succeq Z$, then it implies that $X \succeq Z$.

    - While (1) and (2) might seem to hold fairly well for an ordinary market, (3) is considered as an assumption that extremely models the behavior of the consumer.

    - It relies on the fact that if we prefer $X$ over $Y$, and $Y$ over $Z$, then we will prefer $X$ over $Z$ if given a choice between them. While this would seem obvious, it does not really hold universally.

    - How can you be so sure that if you are given to choose between $X$ and $Z$, you are choosing $X$? This question is persistent, but for the sake of simplicity, we will assume that (3) holds fairly well.

4. **Monotonicity**: For two bundles $X = (x_1, x_2, ..., x_n)$ and $Y = (y_1, y_2, ..., y_n)$, if we have $\forall i \in [1,n], x_i \geq y_i$ then we have $X \succeq Y$.

    - This assumption is the mathematical way of the saying, `More is better`.
    - While this is usually true, this is not a universal assumption. For example, while a consumer might want more cakes and more sweets, he might not want to have more of both, since this will cause health problems to the consumer.

5. **Convexity**: For two bundles $X$ and $Y$ such that $X \sim Y$, we have $\forall \lambda \in [0,1]$, we have $\lambda X + (1 - \lambda) Y \succeq X$.

    - This assumption says that a consumer never prefers any extreme bundles, but rather a diversified combination of these bundles.

    - This is a very reasonable assumption, since as consumers, there is no reason why to have either more of one or more of other, but rather a balanced combination of the extremes.
