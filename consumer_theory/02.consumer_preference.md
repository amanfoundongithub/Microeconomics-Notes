# Consumer Preference

The first topic we want to understand in this section will be to model the consumers' preferences and understand how they make decisions when faced with a set of choices.

After reading this section, you will be able to understand how to model the consumer preferences mathematically.

## 📦 Consumption Bundle

The first step in modelling the consumer preference is to first understand the way in which we can represent the consumption.

More specifically, suppose there are $n$ goods available to a user for consumption. Suppose a consumer has a consumption of $x_i$ of the $i^{th}$ good. How do we represent the overall consumption of the consumer?

This question is important, because we will use the notation discussed here in the rest of the discussion. For now, how will we answer this question?

In economics, we typically call this overall consumption by the consumer as their `consumption bundle`.

To ensure that there is no mathemtical way of comparing the bundles, we can write the consumption bundle as a tuple of $x_i$ as follows:

**Consumption Bundle of Consumer = $(x_1, x_2, ..., x_n)$**

Usually, economists prefer to denote this by capital letter $X$. Thus, we will denote the consumption bundle in the description as either $X$ or $(x_1, x_2, ..., x_n)$, whichever suits the context.
